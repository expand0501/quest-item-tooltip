## Описание
Подсказка предмета показывает, какому из ваших активных заданий он нужен, сколько штук требуется и где находится заказчик.

```
Нужно для заданий:
 * Сидорович (Кордон): принести 3 - у вас 1
 * Бармен (Росток): принести 1, состояние не ниже 60% - у вас 0
 * Доставить: Волк (Кордон)
```

## Возможности
- **Имя и локация заказчика** (только название локации, без точного места)
- **Сколько нужно и сколько у вас**, цветом: зелёный = хватает, жёлтый = не хватает, красный = нет
- **Минимальное состояние**, если задание его требует (например, оружейные задания warfare)
- Поддерживаются задания «принеси предмет», задания с несколькими предметами (и **необязательными дополнительными**), сюжетные задания DRX «найти предмет» и **посылки** (видно, кому доставить)
- Артефакты в контейнерах учитываются
- Работает в инвентаре, тайниках, торговле и окне обыска; показываются только принятые задания
- Каждую часть подсказки (заказчик, локация, название задания, количество, доп. предметы, посылки) можно отключить, настраивается в MCM
- Исправляет режим иконок **Crafting Info in Tooltips** (Utjan): подписи больше не уезжают под иконки и за край подсказки. Исправление отключается в MCM
- Ничего не делает каждый кадр: задания читаются только при показе подсказки

## Установка / удаление
- Установите zip через MO2 как новый мод. Конфликтов не известно, совместим со значком задания из QoL Bundle.
- **Можно ставить и удалять посреди прохождения**: мод ничего не сохраняет в сейв.

## Сообщить об ошибке
Пишите **сюда** и приложите:
- `xray_*.log` из `Anomaly\appdata\logs\` (сначала включите *Debug log* в MCM мода)
- версию мода, версию GAMMA, движок (modded exes или Quark)
- что произошло и что ожидалось, шаги для повторения
- скриншот подсказки
