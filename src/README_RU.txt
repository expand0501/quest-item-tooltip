Quest Item Tooltip 1.0.0, автор Expand
Для S.T.A.L.K.E.R. Anomaly / G.A.M.M.A.

ЧТО ДЕЛАЕТ
Когда вы наводите курсор на предмет, который нужен для одного из ваших активных заданий, в подсказке
появляется блок:

  Нужно для заданий:
   * Сидорович (Кордон): принести 3 - у вас 1
   * Бармен (Росток): принести 1, состояние не ниже 60% - у вас 0
   * Доставить: Волк (Кордон)

- кому нужен предмет и на какой локации сейчас этот человек (только название локации, без точного места)
- сколько нужно для задания и сколько у вас есть (зелёный - хватает, жёлтый - не хватает, красный - нет)
- минимальное состояние, если задание его требует
- работает в инвентаре, тайниках, торговле и при обыске

Поддерживаемые задания: "принеси N предметов" (большинство заданий на предметы в GAMMA, в том числе
задания на оружие от командиров группировок), задания на несколько предметов с дополнительными
предметами, задания DRX storyline "найти предмет" и посылки из заданий на доставку (показывает, кому их
доставить). Артефакт в контейнере тоже считается для заданий на артефакты. Показываются только
принятые задания. Работает вместе с маленьким значком задания, который рисует QoL Bundle из GAMMA.

ТРЕБОВАНИЯ
- G.A.M.M.A. (или Anomaly 1.5.2 с modded exes)
- MCM (есть в GAMMA), не обязательно: без него используются настройки по умолчанию

УСТАНОВКА (MO2)
Установите архив через MO2 ("Install a new mod from an archive") и включите его. Конфликты не известны.
Можно ставить и удалять посреди прохождения: мод ничего не сохраняет, он только читает данные заданий.

MCM -> "Квестовые предметы в подсказке" (все настройки применяются сразу)
  Включить                  - по умолчанию вкл.
  Имя заказчика             - по умолчанию вкл.
  Локация заказчика         - по умолчанию вкл.
  Название задания          - название из КПК, по умолчанию выкл.
  Сколько у вас есть        - по умолчанию вкл. (предметы в тайниках не считаются)
  Дополнительные предметы   - по умолчанию вкл.
  Посылки для доставки      - по умолчанию вкл.
  Исправить раскладку иконок Crafting Info - по умолчанию вкл. (см. СОВМЕСТИМОСТЬ)
  Журнал отладки            - по умолчанию выкл.

СОВМЕСТИМОСТЬ
"Crafting Info in Tooltips" (Utjan, есть в GAMMA) с включёнными иконками рисует подписи
"Используется для крафта / приготовления" не на своём месте: у предметов с длинным описанием подпись
уезжает под иконки, а если подсказка не помещается на экран, подпись встаёт на первую строку
характеристик, а иконки уходят под подсказку. Этот мод расставляет эти блоки заново: подпись, под ней
иконки, всё под описанием и характеристиками; только если так не помещается на экран, - столбцом справа
от характеристик. Отключается в MCM. Без Crafting Info ничего не делает.

ПРОИЗВОДИТЕЛЬНОСТЬ
Ничего не выполняется каждый кадр. Список нужных предметов читается из активных заданий только при
построении подсказки (не чаще раза в секунду), а инвентарь пересчитывается только для предметов,
которые нужны заданию.
